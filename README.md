# תפילתי

אפליקציית אנדרואיד למעקב שבועי אחרי 21 התפילות: כמה במניין, כמה בסך הכול, ותזכורות.

## הורדה

**[הורדת האפליקציה (tfilati.apk)](https://github.com/luach-sport/tfilati/releases/latest/download/tfilati.apk)**

הקישור תמיד מוביל לגרסה האחרונה.

### התקנה בטלפון
1. פותחים את הקישור בטלפון ומורידים את הקובץ.
2. פותחים את הקובץ שירד. בפעם הראשונה הטלפון יבקש לאשר "התקנה ממקור לא ידוע". מאשרים.
3. מתקינים ופותחים. במסך הפתיחה בוחרים יעדים, שעת תזכורת ועיר.

**עדכון:** מורידים שוב מאותו קישור ומתקינים מעל. הנתונים נשמרים.

## מה יש באפליקציה
- **השבוע שלי:** טבעת התקדמות ליעד המניין (ברירת מחדל 10) וליעד הכולל (15), שלוש התפילות של היום, וטבלה של כל השבוע.
- **סימון בלחיצה:** במניין, ביחיד או לא התפללתי, ואם רוצים גם איפה. אפשר לבטל ולתקן ימים קודמים.
- **ברכות:** מסך "יישר כוח" כשעומדים ביעד, עם מאמרי חז״ל, וגם ברכות על יום מלא וחצי יעד.
- **היסטוריה:** גרף שבועי וחודשי, רצף שבועות, ממוצע, פילוח לפי תפילה.
- **תזכורות:** סיכום לילי בשעה שבוחרים, כמה תזכורות לכל תפילה, תזכורת למנחה לפני השקיעה, וכפתורי סימון ישר מההתראה.
- **שקט בשבת ובחג:** אין התראות מלפני כניסת שבת או חג ועד צאתם (לפי העיר שנבחרה).
- **פרטיות:** כל הנתונים נשמרים רק בטלפון. גיבוי ושחזור לקובץ מתוך ההגדרות.

אם התזכורות לא מגיעות: הגדרות הטלפון ← אפליקציות ← תפילתי ← סוללה ← "ללא הגבלה".

## איך זה בנוי
- `www/`: האפליקציה עצמה (HTML, CSS ו־JavaScript, בלי תלויות).
- `android-res/`: אייקונים, אייקון התראה ומסך פתיחה.
- `scripts/`: הכנת גופנים, ותיקון פרויקט האנדרואיד שנוצר עם Capacitor.
- `.github/workflows/build.yml`: כל דחיפה ל־main בונה APK חתום ומפרסמת אותו ב־Releases. גרסת רשת מתפרסמת גם ב־GitHub Pages.
- `signing/release.jks`: מפתח החתימה, מוצפן. הסיסמה שמורה בסוד `TFILATI_KEY_PASS` של הריפו.
